One satirical sentence about a lawmaker who wants to regulate crypto but
cannot convert a file to PDF — 201 characters, one line. Senator Keller
spends 3 hours and 47 minutes failing to turn his 12-page crypto bill
into a PDF, files it as a .docx instead, asks his intern to "just print
the blockchain", and then votes to regulate it. Named person, concrete
numbers, named artefacts (.docx, PDF, the blockchain), and a second twist:
he does not just fail at the file — he legislates the technology he
cannot operate.

## Run it

```sh
python3 main.py
```

`main.py` is deterministic: it writes the single line above to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`) with no
trailing newline. Same output on every run — no randomness, no clock, no
network, no input.
